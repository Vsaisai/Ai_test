# VN Shelf 0.4.10 для Android

- Игру из F95Zone можно добавить в личные полки и перенести на другое устройство через экспорт и импорт отметок.
- Поиск по локальному каталогу F95Zone получает страницы результатов из SQLite. Импорт запоминает пропуски, чтобы вернуться к ним позже.
- При замене полок приложение проверяет отметки до сохранения изменений. Если файл содержит некорректную отметку, прежние полки сохраняются.

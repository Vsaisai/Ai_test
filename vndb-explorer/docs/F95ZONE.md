# Каталог F95Zone

F95Zone подключён как **источник метаданных**: приложение собирает сведения об играх и ведёт пользователя на
исходную страницу и официальные страницы разработчика. Файлы игр, ссылки на скачивание, зеркала и репаки
приложение не читает, не хранит и не показывает.

Включается в «Настройки → Что показывать → Показывать всё», затем «Дополнительно → F95Zone».

## Откуда берутся данные

| Что | Адрес | Когда |
|---|---|---|
| Список игр (новые и обновлённые сверху) | `/sam/latest_alpha/latest_data.php?cmd=list&cat=games&page=N&sort=date&rows=90` — публичная JSON-лента страницы «Latest updates» | кнопка «Обновить» (до первой страницы без изменений) или «Загрузить полностью» |
| Названия тегов и префиксов (движок, статус) | `/sam/latest_alpha/` (объект `latestUpdates`) | перед чтением списка; если страница требует входа — встроенный снимок 154 тегов |
| Описание, официальные ссылки | `/threads/<id>/` — публичная страница игры | только когда пользователь открывает игру; не чаще раза в неделю на игру |

Основания (проверено 9 ноября 2026):

- `robots.txt`: для `User-agent: *` эти пути разрешены, `Content-Signal: search=yes, ai-train=no`. Каталог
  со ссылками и короткими выдержками — это разрешённое «search».
- Правила сайта (`/help/terms/`) не запрещают автоматическое чтение публичных страниц.
- Официального API нет. Лента — внутренний интерфейс страницы сайта: работает без входа, но не
  документирована и может измениться без предупреждения. Для коммерческого использования стоит получить
  письменное разрешение владельцев сайта (форма `/pages/contact/`).

| Поле | Источник | Примечание |
|---|---|---|
| Название | лента | |
| Разработчик | лента (`creator`), уточняется со страницы | |
| Описание | страница игры | выдержка до 1200 знаков, на языке оригинала, с указанием источника |
| Теги | лента (по словарю), страница игры | |
| Версия | лента | |
| Дата обновления | лента (`ts`), страница игры (`Thread Updated`) | |

| Движок | префиксы | как статус |
| Обложка | лента / страница игры | показывается по прямой ссылке с сайта, приложение её не сохраняет; размыта, пока обложки не открыты в настройках |
| Рейтинг, лайки, просмотры | лента | |

| Официальные страницы | страница игры | только домены из белого списка (Patreon, SubscribeStar, itch.io, Steam, DLsite, Gumroad, Ko-fi, Fanbox, Fantia, GOG, Nutaku, Johren, X, Discord) и только **выше** раздела DOWNLOAD |

## Правила импорта

- Не чаще одного запроса в 2 секунды на всё приложение. User-Agent называет приложение. Без cookies и входа.
- Ответ 429/403, проверка Cloudflare или DDoS-Guard, капча, страница входа → импорт **останавливается** и
  показывает причину. Уже прочитанное сохраняется. Ничего не обходится.
- Игры с тегами `loli` и `shota` не показываются никогда. Хранится только номер темы, чтобы не читать её снова.
- Присутствие игры на F95Zone не считается подтверждением легальности её распространения. Об этом пишется
  на каждой странице.

## Совпадения с VNDB (объединение дублей)

Сильнейший признак побеждает:

1. та же страница игры (Steam app, itch.io-игра, DLsite) у релиза ровно одной новеллы VNDB;
2. название + страница разработчика (Patreon, SubscribeStar), которая указана у релизов этой новеллы;
3. название + имя разработчика;
4. название, которое есть ровно у одной новеллы 18+.

Найденная игра открывает страницу новеллы VNDB, а там появляется блок «Каталог сообщества F95Zone».
Игры без пары показываются отдельно (раздел `#/f95`, полка «Западные игры» на главной).

## Устройство

- `crates/core/src/external/mod.rs` — интерфейс `Provider` (`prepare`, `list`, `details`), модель `ExtGame`,
  общий сценарий `refresh`, политика контента, белый список официальных сайтов.
- `crates/core/src/external/f95zone.rs` — `F95Zone: Provider`: запросы, проверки ответов, разбор ленты и страницы.
  Другие источники подключаются новой реализацией `Provider`, остальная логика не меняется.
- `crates/core/src/external/store.rs` — `external.sqlite` в папке данных (отдельно от базы VNDB): игры,
  совпадения, состояние импорта, поиск.
- `crates/core/src/external/matching.rs` — индекс VNDB и правила совпадений.
- `crates/server/src/external_api.rs` — `/api/ext/status`, `/api/ext/refresh`, `/api/ext/search`,
  `/api/ext/tags`, `/api/ext/game/:source/:id`.
- `web/js/external.js` — список, страница игры, полка на главной, блок на странице новеллы, настройки.

Для разработки `VNSHELF_F95_BASE=http://127.0.0.1:<порт>` направляет запросы на локальный тестовый сервер
(принимаются только адреса `127.0.0.1` и `localhost`).

## Ограничения

- Лента и вёрстка страниц не документированы. При изменении сайта разбор может сломаться; ошибка будет
  видна в настройках («Последнее обновление остановлено…»).
- Если словарь тегов на `/sam/latest_alpha/` требует входа, используется встроенный снимок 154 тегов. Новые
  теги в списке будут пропущены до открытия страницы игры, статус и движок — тоже.
- Совпадения по одному названию возможны ошибочные (берётся только единственная новелла 18+) и пропущенные
  (разные написания).
- Описания на английском. Машинный перевод, как для VNDB, можно добавить отдельно.

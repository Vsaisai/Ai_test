VN Shelf {VERSION} — офлайн-каталог визуальных новелл (VNDB) для ПК
=====================================================================

Вся база VNDB (около 67 тыс. новелл, теги, релизы, ссылки) хранится у вас на компьютере.
Подборки, теги по категориям, поиск по обязательным/желательным тегам, ссылки «где скачать
или купить» (itch.io, Steam, DLsite, vngames.ru и др.), языки игры — готовые релизы и патчи,
профиль с достижениями.

Поиск — строка сверху; фильтры — колонка слева на странице поиска (на узком окне — кнопка-воронка).
Клавиши: «/» — поиск, Esc — закрыть панель фильтров.

ЗАПУСК
------
Windows:      дважды щёлкните «Start VN Shelf.bat».
Linux:        ./start-vn-shelf.sh
macOS:        дважды щёлкните «Start VN Shelf.command»
              (если macOS не даёт запустить: Терминал → xattr -dr com.apple.quarantine <эта папка>).

Откроется окно приложения (Edge/Chrome без адресной строки, иначе обычный браузер).
При первом запуске нажмите «Скачать базу VNDB» (~190 МБ, 1–3 минуты).
Дальше всё работает без интернета; новые новеллы и релизы приложение подтягивает само.

Остановить сервер:  «Stop VN Shelf.bat» / ./stop-vn-shelf.sh (или закройте окно «VN Shelf server»).

ПАПКИ
-----
server/                     сервер
  vndb-web(.exe)            программа-сервер (база, поиск, API, кэш обложек)
  start-server              запуск с видимым журналом
  start-server-lan          запуск для телефона в той же Wi-Fi сети:
                            откройте на телефоне http://IP-компьютера:8080
                            (пароля нет — только для домашней сети)
  config                    порт (по умолчанию 8080)
  data/                     ВАШИ ДАННЫЕ: база VNDB, «Мои полки», кэш обложек.
                            Сюда же можно положить shelves.json / sources.json
                            (примеры: shelves.example.json, sources.example.json).
client/                     клиент
  web/                      интерфейс (HTML/CSS/JS) — сервер берёт его отсюда, можно править
  open-client               открыть интерфейс окном-приложением
  cli/vndb-explorer(.exe)   консольный клиент (та же база из server/data):
                            vndb-explorer search -m "Science Fiction" -w "Time Travel" --links

ОБНОВЛЕНИЕ ПРОГРАММЫ
--------------------
Когда выходит новая версия, программа сообщает об этом (раз в сутки, если есть интернет).
Распакуйте новую версию в отдельную папку и перенесите туда папку server/data из старой —
база и ваши полки сохранятся.

Windows может показать предупреждение SmartScreen (программа не подписана):
«Подробнее» → «Выполнить в любом случае».

Данные: VNDB (https://vndb.org), лицензия ODbL. Исходный код: https://github.com/Vsaisai/Ai_test

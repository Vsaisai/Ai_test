## VN Shelf для ПК

Офлайн-каталог VNDB: вся база (≈67 тыс. новелл, включая 18+) на вашем компьютере, полки, теги
по категориям, поиск по обязательным/желательным тегам, ссылки «где скачать или купить».

### Запуск
1. Скачайте архив для своей системы и распакуйте.
2. Windows — «Start VN Shelf.bat», Linux — `./start-vn-shelf.sh`, macOS — «Start VN Shelf.command».
3. При первом запуске нажмите «Скачать базу VNDB» (~190 МБ).

В архиве две папки: `server` (сервер и ваши данные в `server/data`) и `client` (веб-интерфейс,
запуск окна-приложения и консольный клиент). Подробности — в README.txt внутри архива.

Чтобы пользоваться с телефона в той же сети, запустите `server/start-server-lan` и откройте
`http://IP-компьютера:8080`, либо поставьте Android-приложение из релизов `mobile-v*`.
